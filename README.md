# O Emissor dos Três Sóis

Task 1 (Capítulo 1)
"Altere o perfil para um mago ancião e sábio de 80 anos, debilitado fisicamente."

Task 2 (Capítulo 3)
"Recomponha que o artefato só funciona exposto à radiação direta de uma estrala viva/Sol."

Task 3 (Capítulo 4)
"Mantenha o navegador leal e adicione que ele sacrificou sua vida para abrir as portas."

Task 4 (Capítulo 5)
"Altere a câmara para um terraço aberto banhado pela luz solar direta de três sóis."
